# Retail Sales Analysis and Prediction

## Overview

This project performs end-to-end analysis of a real-world retail sales dataset.

## Objectives

- Analyze retail sales and profit
- Identify important sales patterns
- Visualize category and regional performance
- Analyze customer and product performance
- Predict sales using machine learning

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Machine Learning
6. Model Evaluation
7. Business Insights

## Machine Learning

A Random Forest Regression model was used to predict sales.

Evaluation metrics:
- MAE
- MSE
- RMSE
- R² Score

## Conclusion

The project demonstrates how data science techniques can be applied to real-world retail data to discover patterns, generate insights, and build predictive models.
